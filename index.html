Quick Start (2 minutes)

  1. Add people — go to 👥 Profiles. Use ➕ Add One Person, or 📋 Add Many at Once and paste a list (one person per line: Name, Birthday). For big rosters, import a CSV in 💾 Import / Export.
  2. Weekly check-in — once a week, open ⚖️ Weekly Check-In. Type each person's weight and resting heart rate. Press Enter to move down the list. It saves as you go.
  3. Daily workouts (Mon–Fri) — open 🏃 Daily Workouts, pick the day, and type the workout and minutes for each person. If everyone did the same thing, use Quick fill to fill the whole list in one click.
  4. See progress — on 👥 Profiles, click a name to see their weight chart, heart-rate history, and workouts.
  5. Back up — in 💾 Import / Export, download a backup now and then.

Good to know

  • Median heart rate is calculated automatically from all of a person's weekly heart-rate entries (the middle value — not thrown off by one odd reading).
  • Use the ◀ ▶ arrows to view or fix past weeks. This week jumps back to today.
  • To erase one entry, just clear the box.
  • Data stays on this computer, in this browser. Nothing is sent online.
